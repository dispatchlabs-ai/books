# Books interface design

Start with the [AI-operated interface, v2](ai-first-v2/README.md): three core
experiences and a contextual decision state, each designed for desktop and
mobile using shadcn components. This is the current product direction for
personal and business finances.

The earlier atlas below is retained as an operation inventory, not the proposed
navigation structure.

[Desktop and mobile design atlas, v1](screens-v1/README.md) maps all 111 existing
backend operations to proposed pages and workflows. The [visual gallery](screens-v1/index.html)
contains 37 paired imagegen boards with desktop and mobile treatments, including
one explicitly planned cash-projection screen. These are synthetic design concepts;
The current implementation is documented in [web](../../web/README.md).
